## ねこちゃんを ゴールまで つれていこう 🐱

小学1年生向けの、やさしいプログラミングあそびです。
やじるしカードを順番に選んで「じっこう」を押すと、ねこちゃんがマス目をゴールまで進みます。
「命令を並べる」「実行する前に結果を予想する」「間違いを直す」という、プログラミングの土台を遊びながら体験できます。

紙のワークブック版と同じ猫ちゃん・同じ8問・同じ方向（**まえ＝うえ**）で作ってあるので、紙で練習してから画面に移っても迷いません。

### あそびかた

1. **やじるし**（まえ・うしろ・ひだり・みぎ）をタップすると、下の「れっしゃ」にカードが並びます。
2. ゴール（⭐）まで行けるように、カードを順番に並べます。
3. **「じっこう」** を押すと、ねこちゃんが1マスずつ動きます。
4. ゴールに着けばクリア。着かなければ ↩︎（1つ戻す）や🗑（全部消す）で並べ直して、もう一度。

- 上の数字（1〜12）でもんだいを選べます。
- **もんだい9〜12は「くりかえしカード」**を使います。やじるしを選んだあとに黄色い数字（2〜6）を押すと、その方向へまとめて進みます（例：▶ ＋ 4 で右に4マス）。カードの枚数に上限があるので、くりかえしを使わないとゴールできません。
- ⟲ でねこちゃんをスタートに戻します。
- 🔊 で音のオン／オフを切り替えます。
- パソコンでは **矢印キー**でカード追加、**数字キー2〜6**でくりかえし、**Enter**で実行、**Backspace**で1つ戻す、も使えます。

### ローカルで動かす

ビルド不要です。`game.html` をブラウザで開くだけで動きます（ダブルクリックでOK）。

### GitHub Pages で公開する

このリポジトリには `.github/workflows/pages.yml` が用意済みで、`master` ブランチに push すると自動でリポジトリ全体が GitHub Pages に公開されます。

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** で **「GitHub Actions」** が選ばれていることを確認します。
3. `master` ブランチに push すると、`https://<ユーザー名>.github.io/<リポジトリ名>/game.html` で公開されます。

スマホやタブレットからそのURLを開けば、子どもがそのまま遊べます。ホーム画面に追加するとアプリのように使えます。

### もんだいを増やす・変える

`game.html` の中ほどにある `LEVELS` を編集します。1問はこの形です。

```js
{no:13, title:"すきな なまえ", hint:"ヒントの もじ",
 c:5, r:5,            // よこ5マス・たて5マス
 start:[1,5],         // スタート（左から1・上から5）
 goal:[5,1],          // ゴール
 walls:[[3,5],[3,4]], // かべ（なければ [] ）
 gem:[1,3],           // ハート（なければ null ）
 rep:true,            // くりかえしカードを つかう問題なら true
 max:4},              // カードの まいすう上限（なければ 省略）
```

座標は「左から何番目・**上から**何番目」です（`row 1` がいちばん上）。
`c` と `r` を変えれば盤の大きさも変わります。
`rep:true` にすると黄色い数字ボタンが表示され、`max` を小さくするほど「くりかえしを使わないと解けない」問題になります（やじるし＋数字で2枚と数えます）。

### カスタマイズのヒント

- ねこちゃんの色や表情は CSS の `.face` まわり、猫を別の動物にしたい場合もここを触ります。
- 難しくしたいときは、かべを増やす／盤を大きくする／ハートを2個置く、などが手軽です。
